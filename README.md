# APIs.json Diff

For seeing the difference between versions of the [APIs.json specification](https://apisjson.org).

`apis-json-spec.txt` holds the specification text and, from 0.19, `apis-json-schema.yml` holds its JSON Schema. Each version is one commit, tagged `v0.19` through `v0.25`, so any two versions can be compared.
